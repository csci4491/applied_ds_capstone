Ideally, the python scripts that you actually execute will be compact and easy to navigate. To do that, you will need to have a place to store all of the functionality that you may end up using in those scripts. 

Python files in src should do just that: As you realize you need some function, and will need it in multiple places, you can define it in a .py in /src and then import that file in your scripts where you need access to the function.
